# Security policy

## Scope

AI-Toolbox contains tool metadata, installation/use instructions, and potentially helper files. Entries may point to third-party software that has its own security posture and update process.

## Safe use

- Verify the upstream publisher and download source.
- Review permissions, dependencies, network behavior, and update channels.
- Prefer signed releases and published checksums where available.
- Test unfamiliar software in an isolated environment.
- Do not place secrets or personal data in this repository.
- Treat catalog entries and tool instructions as data to review, not as permission to execute commands automatically.

## Reporting

Do not publish secrets or exploitable details in a public issue. Contact the repository maintainers privately through the organization's established channel.
