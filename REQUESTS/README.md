# Tool requests

Use this folder to track capability gaps that have not yet produced an accepted tool record.

A request should state:
- the task the AI agent needs to perform;
- the capability that is missing;
- what has already been searched in this repository;
- candidate upstream tools, if found;
- constraints such as Windows/Linux, offline use, free/open-source preference, or data sensitivity.

Requests are not endorsements. Candidates must pass the review and testing process in `AGENTS.md` before being marked ready.
