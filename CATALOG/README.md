# Tool catalog

The machine-readable index is [tools.json](tools.json). Each entry points to a human-readable `TOOLS/<category>/<tool-id>/TOOL.md` record.

The [Skill-to-Tool dependency map](SKILL-MAP.md) connects all 25 workflows in Personal-AI-Library to concrete software capabilities, candidate tools, and a prioritized research queue. Crypto trading framework candidates and their BingX/Binance/Bybit product compatibility are compared in [ENGINE-COMPATIBILITY.md](../TOOLS/crypto-engines/ENGINE-COMPATIBILITY.md). Redocly CLI provides OpenAPI linting and Arazzo-based API workflow checks. Candidates in that map are not automatically reviewed or approved.

Search the catalog before proposing a new tool. A catalog entry is not proof that the tool is installed or verified; always check its status, compatibility, and last verification date.
